# やすみタイム

時間を守って休憩すると、ポイントがたまる家族向けタイマーアプリ。Android・パソコンに「アプリ」として入れて使えます（PWA）。

## ファイル
`index.html`（本体）／`manifest.webmanifest`・`sw.js`・`icon-192.png`・`icon-512.png`（アプリ化に必要）／`firestore.rules`（保存のルール）。**全部同じフォルダに置いて公開してください。**

## 画面と役割
| 役割 | できること |
|---|---|
| 子ども | タイマー、休憩、ポイント獲得、ごほうびと交換 |
| 保護者 | 時間・ポイントの設定、ごほうび登録、承認、履歴、ポイント調整 |
| 所有者 | 保護者の機能 ＋ 家族コード、役割の変更、合言葉の変更 |

## 合言葉（いちばん大事）
- 所有者が家族をつくると、**最初に合言葉を決める画面**が出ます。決めるまで他の画面には進めません。
- 数字でも文字でもOK、長さも自由です。
- 「保護者パネル」「所有者パネル」を開くとき、休憩をとちゅうでやめるとき、ログアウトのときに必要です。子ども画面や「モード」画面にもどると、また聞かれます。
- 5回まちがえると1分間ロックされます。
- 所有者が合言葉を決めるまで、保護者は保護者パネルを使えません。

## 休憩のしくみ
1. 「タイマーをはじめる」→ 設定した時間（初期30分）
2. 時間になると画面の上に知らせ → 猶予（初期3分）のカウント
3. 猶予内に「休憩する」→ 全画面の休憩（初期5分）→ 終わるとポイント
4. 猶予をこえると「休憩をしてください」画面。休憩はできますがポイントなし

保護者パネルの設定で、時間・ポイントのほか、**知らせの音／バイブレーション／休憩中に画面を暗くしない**を切りかえられます。

## 追加した機能（バージョンアップ）

### ポイントを続けたくなる仕組み
- **連続日数ボーナス**: 休憩できた日が続くと、3日ごと・7日ごとにボーナス（ポイント数は設定で変更）
- **レベルアップ**: もらったポイントの合計でレベルが上がり、称号（みならい → ひよっこ → … → 休憩の神）が変わる
- **デイリーミッション**: 「休憩を3回できる」「クイズに3問せいかい」など。達成でボーナス。保護者が追加・削除できる
- **貯金ゲージ（もくひょう）**: ごほうびの 🎯 ボタンで目標にすると、ためた割合がゲージで見える
- **バッジ・実績**: 14種類。条件を満たすと自動でゲット
- **きせかえテーマ**: レベルが上がると使える色が増える（ノーマル／うみ／もり／さくら／うちゅう／ほのお）

### 休憩中の画面・使いすぎ防止
- 休憩中に **目の体操・ストレッチ・豆知識** を15秒ごとに表示
- 休憩中の **クイズ**（正解で +2pt、1日5問まで。設定で変更可）
- **1日の使用上限**（超えるとその日はタイマーを開始できない）
- **使えない時間帯**（例: 21:00〜7:00）

### 保護者向け
- **レポート**: この7日間の使用時間・休憩できた回数・もらったポイントを、子どもごとにグラフ表示
- **子どもごとの設定**: 休憩までの時間・休憩の長さ・猶予・ポイント・1日の上限を人別に変更（空らんは家族の標準を使う）
- **ごほうびの制限**: 1日◯回／1週間◯回／期限を、ごほうびごとに設定
- **承認の通知**: 子どもが交換を申しこむと、アプリを開いている保護者の画面に通知（子どもにも承認の知らせ）。通知を許可すると、別の画面を見ていても届く
  - ※ アプリを完全に閉じているときの通知（プッシュ通知）には、別途サーバーの仕組みが必要で、今回は入っていません。

### Family Link との併用
このアプリは「休憩の習慣づくり」用で、端末そのものを制限する機能はありません。Google の **Family Link** は、アプリの利用時間・就寝時間の端末ロックができるので、組み合わせるのがおすすめです。
- やすみタイム: 休憩を守るとポイントがたまる（やる気づくり）
- Family Link: 端末そのものの使用時間・夜のロック（強制力）

## ログインとデータ保存
ログイン画面の「🔑 Googleアカウントでログイン」を押すと Google の画面が開き、アカウントを選べます。ポイントや設定はアカウントごとに保存されます。これには Firebase の設定が必要です。

### Firebase の設定
1. https://console.firebase.google.com でプロジェクトを作る
2. Authentication → ログイン方法 → **Google** を有効にする
3. Firestore Database を作成
4. Firestore の「ルール」に `firestore.rules` の中身を貼って公開
5. プロジェクトの設定 → ウェブアプリを追加 → `firebaseConfig` をコピー
6. アプリのログイン画面の「Firebase設定を貼りつける」に貼って保存
7. アプリを **https で公開**（Firebase Hosting / GitHub Pages / Netlify など）。試すだけなら `python3 -m http.server 8000` → `http://localhost:8000`
8. Authentication → 設定 → **承認済みドメイン** に公開したドメインを追加

設定なしで動きだけ見たいときは、「ログインなしでためしてみる」（この端末だけに保存）。

## Android・パソコンにアプリとして入れる
公開した https のアドレスを **Chrome** で開きます。
- **Android**: 右上の︙メニュー →「アプリをインストール」（または「ホーム画面に追加」）。アプリ内の「📲 インストール」ボタンが出たときはそれでもOK
- **パソコン（Chrome / Edge）**: アドレスバー右の「インストール」アイコン、またはアプリ内の「📲 インストール」ボタン

インストールすると、アイコン付きで全画面のアプリのように開きます。通知を許可すると、別の画面を見ていても休憩の知らせが届きます。

## 家族で使う流れ
1. 所有者が Google でログイン →「家族をつくる」→ 合言葉を決める
2. 所有者パネルの **家族コード（6文字）** を家族に伝える
3. 家族は自分の Google アカウントでログイン →「家族に参加する」（最初は「子ども」）
4. 所有者パネルで、保護者にする人の役割を変更

## 知っておいてほしいこと
- ブラウザ・PWAのアプリなので、**端末自体を強制ロックすることはできません**。休憩画面は別のアプリやタブを開けば避けられます。習慣づくりのためのものです。端末ごとロックしたい場合は、Android の「Family Link」などの機能と組み合わせてください。
- 合言葉と役割の確認は画面側の仕組みです。ポイントの計算もブラウザ側で行うため、詳しい子どもなら書き換えられる可能性があります（家族内で信頼して使う前提です）。
- 合言葉は https で公開したアプリでのみ、強い方式で保存されます。

## 時間になったらロック（新機能）

1. 設定した時間（初期30分）になると、画面上部に知らせが出ます。
2. 猶予内（初期3分）に「休憩する」を押すと、通常の休憩（ポイントあり）。
3. 猶予をすぎると、**「設定した時間に終了しました」の真っ暗なロック画面**になり、休憩の長さ（初期5分）だけ待つと自動で使えるようにもどります（ポイントなし）。
4. 解除したいとき：ロック画面の「解除する」→ **保護者の合言葉** または **作者のマスターパスワード** → 残りの休憩を何分にするか入力。**0分なら「もう休憩が終わりです」** になり、すぐ使えます（この休憩ではポイントは入りません）。
5. 保護者パネル → 設定 →「時間になったときのロック」で、自動ロックのオン／オフ、真っ暗にするか、メッセージ、ディスプレイ電源オフを変えられます。

### 作者マスターパスワード
- どの家族でも休憩ロックを解除できるパスワードです。ソースコードには書かず、Firestore の `config/master` にハッシュだけ保存します。
- 設定できるのは作者のGoogleアカウントだけ（`index.html` の `CREATOR_EMAILS` と `firestore.rules` の両方で制限）。所有者パネルの「作者マスターパスワード」から設定します。
- ハッシュはログイン済みの誰でも読めるため、**8文字以上の長いパスワード**にしてください。

## アプリ版（Windows / Mac / Android）

| | しくみ | ロック中の動き |
|---|---|---|
| Windows・Mac | Electron（`native/desktop`） | 全画面・最前面。閉じる／最小化できない。設定で画面の電源オフ |
| Android | Capacitor（`native/android`） | 全画面表示＋画面固定。設定で「端末ロック」（端末のロック解除が必要な状態に） |

- Googleログインは、ふつうのブラウザで行い、結果をアプリに受け取ります（アプリ内の画面ではGoogleにログインできないため）。`native-login.html` がその受け口です。
- 作りかた：このフォルダを GitHub のリポジトリに入れると、`.github/workflows/build.yml` が自動で
  ① ダウンロードページとログイン用ページを GitHub Pages に公開、② Windows の exe、Mac の dmg、Android の APK をビルド、③ Releases に置く、を行います。
- ダウンロードページ：`https://ユーザー名.github.io/リポジトリ名/download.html`

### GitHub での手順
1. GitHub で新しいリポジトリ（公開）を作る
2. このフォルダの中身をすべてアップロード（`.github` フォルダも必要。出ない場合は「Add file → Create new file」で `.github/workflows/build.yml` を作って中身を貼る）
3. Settings → Pages → Source を **GitHub Actions** にする
4. Settings → Actions → General → Workflow permissions を **Read and write** にする
5. Actions タブ →「やすみタイム ビルド」→ Run workflow（15〜25分）
6. Firebase の Authentication → 設定 → 承認済みドメインに `ユーザー名.github.io` を追加
7. Firestore のルールを、同梱の `firestore.rules` で更新して「公開」

### アプリ版の限界（正直に）
- OS の機能（Ctrl+Alt+Del からタスクマネージャーで終了、電源ボタン長押し、セーフモード等）までは止められません。Windows は子ども用に「標準ユーザー」アカウントを使い、Android は Family Link／画面固定の「解除時にPINを要求」と組み合わせると強くなります。
- exe・APK・dmg は署名していないため、最初の起動時に警告が出ます（ダウンロードページに手順があります）。
- Android の APK はデバッグ署名です。端末への直接インストール用で、Google Play には出せません。
